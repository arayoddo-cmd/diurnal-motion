# 🌏 일주운동 관측소 (지구의 운동 1차시: 자전과 일주 운동)

지구의 **자전 방향**과, 그 때문에 나타나는 태양·달·별의 **일주 운동 방향**을 3D로 돌려 보며 익히는 수업 자료예요.
교과서 Ⅲ. 태양계 › 2. 지구의 운동 (교과서 238~241쪽, 학습지 8~9쪽) 내용을 따라가요.

> 시리즈: ① 자전과 일주 운동 (이 자료) → ② 공전과 연주 운동 → ③ 달의 위상 변화
> 세 자료 모두 같은 화면 구성과 조작법을 쓰고, 결과는 같은 구글 시트에 차시별 탭으로 모여요.

## 화면 하나, 보기 세 가지

| 보기 | 보여 주는 것 |
|---|---|
| 🌍 우주에서 본 지구 | 23.5° 기운 자전축, 서→동 자전 화살표, 햇빛과 낮·밤. **북극 위에서 보기**를 누르면 시계 반대 방향으로 도는 모습이 보여요. 화면 위에 우리나라 시각과 낮·밤이 표시돼요. |
| ✨ 천구 | 지구가 가운데 있고 별이 천구에 붙어 있어요. 교과서 그림처럼 자전축이 기울어져 있어서 천구 북극(북극성)이 오른쪽 위에 있고, 우리나라가 지구 꼭대기에 와요(남이 왼쪽, 북이 오른쪽). **🌍 실제: 지구가 돈다** / **👀 겉보기: 하늘이 돈다**를 바꿔 가며 같은 현상임을 비교해요 (기차 비유). |
| 🔍 천구 → 지평선 잇기 | 천구 보기에서 **🔍 우리나라로 확대**를 누르면 약 8초 동안 이어지는 장면이 나와요. ① 우리나라로 다가가 지구 표면에 닿은 지평면과 관측자를 보여 주고 ② 지구가 점처럼 작아지면서 지평면이 천구 한가운데로 가면, 돌리지 않아도 그대로 하늘 보기의 '밖에서'와 똑같은 모습이 돼요. 별은 계속 같은 자리에 있어서 두 그림이 같은 하늘임을 알 수 있어요. '밖에서' 화면의 **↩ 천구로 돌아가기**로 거꾸로도 볼 수 있어요. |
| 🧭 지평선 위 관측자 | 🔭 **밖에서 보기**(교과서 반구 그림과 같은 모습)와 **동·남·서·북 하늘 보기**(관측자 눈높이). 화면을 밀면 고개를 돌릴 수 있고, 화면 아래에 왼쪽·오른쪽이 어느 방향인지 나와요. |

공통 조작: ▶ 재생, **+1시간**(정확히 15°씩), 빠르기, ✨ 자취, ➤ 방향 화살표(굵은 길잡이와 큰 화살표), 📐 북극성 고도, 관측 대상(별·태양·달), 지평선 아래도 보기. 관측 장소는 우리나라(북위 37.5°)로 고정이에요.

## 👩‍🏫 수업 모드 (TV·전자칠판용)

넓은 화면(TV·노트북, 폭 1000px 이상)에서는 조작 버튼이 **관측 화면 오른쪽 세로 칸**에 모여 있어서 스크롤하지 않고 조작할 수 있어요. 관측 화면은 화면 높이에 맞춰 크게 나와요. (좁은 화면에서는 버튼이 관측 화면 아래에 있어요)

탭 4개: ① 지구의 자전 ② 천구와 일주 운동 ③ 방향별 별의 움직임 ④ 태양과 달.
3D 화면이 화면 너비를 가득 채우고, 학습지와 같은 빈칸이 있는 정리 카드는 그 아래에 큰 글씨로 나와요. **빈칸을 누르면 하나씩** 답이 보여요. 탭마다 함께 생각할 질문이 있어요.
④ 탭 카드에는 수업 PPT처럼 **태양의 일주 운동 주기 = 하루(1일)**와 **북극성의 고도 = 그 지방의 위도**가 있어요. 위도 줄 아래에는 **북극(90°)·우리나라(37.5°)·적도(0°)**에서 본 반구를 나란히 그린 그림이 있어요. 북극에서는 별이 지평선과 나란히 돌고, 우리나라에서는 비스듬히, 적도에서는 지평선에 수직으로 뜨고 져요. (📐 버튼으로 우리나라의 북극성 고도를 3D로 보여 줄 수 있어요. 3D 화면은 우리나라 위도로 고정이에요)

## 🧑‍🚀 탐사 모드 (학생 태블릿용)

1. **임무 1. 지구의 자전**: 옆에서·북극 위에서 각각 2시간 이상 돌려 본 뒤 보고서 6문제
2. **임무 2. 천구와 일주 운동**: 천구를 남동쪽 높은 곳에서 내려다본 모습으로 시작해요. 자전축(북극성 쪽)이 오른쪽 위로 비스듬하고 천구의 적도가 납작한 타원으로 보여서, 지구 자전과 천체의 일주 운동 방향을 한눈에 비교할 수 있어요. '실제'와 '겉보기'를 각각 2시간 이상 본 뒤 보고서 6문제
3. **임무 3. 우리나라 하늘 관측**: 동·남·서·북 하늘에서 별이 움직일 방향을 **화살표로 예측 → 4시간 재생으로 확인**. 예측 전에 **🔭 밖에서 천구 보기**로 지평선 위 천구 전체를 볼 수 있어요. 별이 지나는 길(흐린 선), 천구 적도 위의 노란 화살표(동 → 남 → 서), 관측자가 바라볼 방향(파란 화살표)이 보여서, 외우지 않아도 관찰해서 추론할 수 있어요. 남쪽 하늘의 답은 위로 살짝 볼록한 완만한 곡선이에요. 마지막으로 태양이 움직이는 순서를 예측해요.
4. **임무 4. 확인 퀴즈**: 형성평가와 같은 유형 20문제 (북두칠성·카시오페이아 시간 계산, 별의 자취 사진으로 방향 찾기, O/X, 1시간에 15° 등)
5. **보너스 🚀 자전 지구 발사대** (임무 4를 마치면 열림): 북극 위에서 본 지구가 시계 반대 방향(서 → 동)으로 돌고(1단계 한 바퀴 10초, 2단계 8초), 우리나라가 위성 바로 아래에 올 때 로켓을 쏴요.
   1단계 연습 발사(멈춘 위성) → 2단계 밤에만 발사(움직이는 위성, 우리나라가 오후 6시~오전 6시일 때만) → 3단계 시간 계산 발사(위성까지 각도를 보고 몇 시간 뒤 쏠지 계산, 1시간 = 15°, 시계 방향 쪽 위성은 360°에서 빼서 계산). 깬 단계 수가 시트의 '보너스 발사대' 칸에 기록돼요.

- 임무는 차례대로 열려요. 모든 학생이 같은 문제를 같은 순서로 풀어요.
- **통과 기준 임무 1~3은 70%, 임무 4는 60%**: 임무마다 처음 고른 답이 맞은 것이 기준 이상이어야 다음 임무가 열려요. (6문제 중 5개, 예측 5개 중 4개, 퀴즈 20문제 중 12개) 못 넘으면 해설을 보고 그 임무를 처음부터 다시 풀어요. 재도전 횟수는 시트의 '재도전 (임무 1·2·3·4)' 칸에 기록돼요.
- 이 단원은 "1시간에 15°"를 외워야 해서 문항에 수치를 넣었어요.
- 진행 상황은 학생 브라우저에 저장돼서 창을 닫았다 열어도 이어서 할 수 있어요.

## 결과 받기 (태양계 탐사대와 같은 시트)

`index.html`의 `SUBMIT_URL`에는 태양계 탐사대와 **같은 Apps Script 주소**가 들어 있어요. 결과는 같은 구글 시트의 **'일주운동 현황'** 탭에 학생 한 명당 한 줄로 쌓여요.

**처음 한 번만: Apps Script를 새 코드로 바꾸기**
1. 태양계 탐사대 결과 시트를 열고 **확장 프로그램 → Apps Script**를 눌러요.
2. 지금 들어 있는 코드에서 `CLASS_CODE`와 `TEACHER_CODE` 따옴표 안의 값을 **메모해 둬요.**
3. 코드를 모두 지우고, 이 폴더의 `apps-script.gs` 내용을 전부 붙여 넣어요.
4. 6~7번째 줄의 `CLASS_CODE`, `TEACHER_CODE`에 메모해 둔 값을 다시 넣고 💾 저장해요.
5. **배포 → 배포 관리 → ✏️(수정) → 버전: 새 버전 → 배포**를 눌러요. ('새 배포'를 누르면 주소가 바뀌니 주의!)
6. 확인: 웹 앱 주소를 브라우저에 넣으면 "✅ 수업 결과 수집기가 작동 중이에요"가 보여야 해요.

태양계 탐사대는 예전과 똑같이 작동해요. 다음 차시(연주 운동, 달의 위상) 자료도 이 코드를 고치지 않고 그대로 써요.

> Apps Script를 바꾸기 전에는 학생 진행 상황이 **저장되지 않을 뿐** 다른 탭에 잘못 쓰이지는 않아요. (자료가 먼저 버전을 확인해요)

**시험해 보기**: 탐사 모드에서 학번 `00000`, 이름은 아무거나, 수업 코드를 넣고 시작하면 **선생님 시험 모드**예요. 모든 임무와 게임 3단계가 처음부터 열려 있어서 원하는 곳으로 바로 갈 수 있어요. 📋 결과에서 **보내기**를 눌러 시트에 '일주운동 현황' 탭과 줄이 생기는지 확인하세요.

**결과 보기**: 첫 화면 오른쪽 아래 **👩‍🏫 교사용 → 교사 코드**. 반별로 나눠 보고, 임무별 완료 인원과 "한 번에 맞힌 수", 학생이 틀린 예측(예: "남쪽 하늘: 오른쪽 → 왼쪽")을 볼 수 있어요.

## 참고

- 지구 지도는 대륙을 단순하게 그린 그림이에요.
- 별자리(북두칠성, 카시오페이아자리, 오리온자리)와 북극성은 실제 위치에 가깝게 넣었고, 나머지 별은 고르게 흩뿌렸어요.
